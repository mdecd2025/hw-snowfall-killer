Tutorial1相關問題

  1. 在製作 HW1 之前是否實際練習 Tutorial1 與 Tutorial2？
    A：是，練習 Tutorial1 與 Tutorial2 可幫助熟悉 Webots 操作界面與控制器程式結構，為 HW1 的製作打下基礎。
  2. Webots 是什麼樣的軟體？它主要用途為何？
    A：Webots 是一款開源的 3D 機器人模擬平台，用於設計、測試與模擬各種機器人行為，常用於教育與研究領域。
  3. 在 Tutorial1 中，學習者需要操作的主要機器人模型名稱是什麼？
    A：主要操作的機器人模型是 e-puck。
  4. 如何在 Webots 中建立並執行一個新的模擬世界（world）？
    A：可透過「File > New World」建立新模擬世界，並用場景樹新增物件與機器人後，按下「Play」按鈕執行模擬。
  5. 請說明如何讓機器人在模擬中移動，並指出相關的程式控制方式。
    A：需撰寫控制器程式（如 Python），使用 `setVelocity()` 控制馬達速度，例：`left_motor.setVelocity(2.0)`。
  6. Tutorial1 中，學習者需要修改哪些參數或檔案來控制機器人的行為？
    A：需修改控制器程式檔（如 `my_controller.py`），調整馬達速度或邏輯流程以影響機器人行為。
  7. 請簡述 Webots 控制器（controller）的功能及其與機器人的關係。
    A：控制器是驅動機器人的程式，讀取感測器資料並控制執行器（如輪子），就像機器人的「大腦」。
  8. 在 Tutorial2 中，機器人需要完成什麼樣的任務或行為？
    A：需讓機器人能避開障礙物並自動移動，完成基本的自主導航。
  9. Webots 中的 "Supervisor" 是什麼？它與一般機器人控制器有何不同？
    A：Supervisor 是一種特殊控制器，能監控整個模擬世界，控制多個物件或機器人，具備更高控制權限。
  10. 請說明如何在 Webots 中進行感測器數據的讀取與應用（例如距離感測器、攝影機）。
    A：需先啟用感測器（如 `sensor.enable(timestep)`），再使用 `sensor.getValue()` 或 `getImage()` 等方法讀取資料。
  11. 若要延伸 Tutorial2 讓機器人具備自主避障能力，你會怎麼設計與實作？
    A：可使用距離感測器資料，設計條件式控制馬達轉向，例如左側感測器讀到障礙就右轉。
  12. 請說明 Webots 中「時間步長（timestep）」的意義，以及它對模擬的影響。
    A：時間步長是模擬中每次更新的時間間隔，數值越小模擬越精細但效率越低，常見為 32 毫秒。
  13. 如何在 Webots 中為機器人新增感測器？請說明基本步驟。
    A：在機器人模型的場景樹中右鍵新增感測器元件（如 DistanceSensor），命名後再於控制器中啟用與讀取。
  14. 請說明如何將 Webots 控制器程式從 Python 改為 C 語言，並指出相關設定。
    A：須撰寫 C 語言控制器檔案，並在 robot 節點中指定 control name，且在「Tools > Make」中編譯該程式。
  15. Tutorial1、2 中，若控制器程式有語法錯誤時，Webots 會如何反應？學員該如何排除？
    A：Webots 會在 console 顯示錯誤訊息，學員應根據提示檢查語法、拼字或函式使用是否正確。
  16. 如何將 Webots 世界（world）或機器人設定檔分享給他人，確保對方可順利開啟模擬？
    A：應將整個包含 .wbt、controllers、protos 等資料夾打包壓縮，對方可直接解壓並打開世界檔運行。
  17. 如果想讓機器人在模擬時產生聲音或播放音樂，Webots 提供哪些方法？
    A：可使用 Sound 裝置元件或呼叫 Webots API 播放聲音檔（如 `.wav`），也可配合 controller 播放。
  18. 請說明如何在 Webots 中同時操作多個機器人，並讓它們各自執行不同控制器。
    A：於場景中新增多個機器人，每個 robot 節點設定不同的 controller 名稱，並建立對應程式檔案。
  19. 在 Webots 控制器中，如何獲得機器人的當前座標位置與朝向？
    A：需透過 Supervisor 控制器使用 `getFromDef()` 搭配 `getField('translation')` 讀取位置資訊。
  20. 請說明 Webots 控制器中感測器資料的單位（例如距離感測器、加速度計），以及如何正確解讀。
    A：距離感測器單位通常為毫米或以 raw 值表示，加速度計為 m/s²，需查閱對應感測器 API 文檔正確轉換。
  21. 如果想要錄製 Webots 模擬畫面並輸出成影片檔，該如何操作？
    A：點選攝影機圖示「Record」功能，模擬結束後可於選單中匯出為影片檔（如 .mp4）。
  22. Webots 中的 PROTO 文件有什麼作用？與 world 檔（.wbt）的關係為何？
    A：PROTO 定義可重複使用的機器人或物件模組，.wbt 檔則是模擬世界實例，引用 PROTO 建立物件。
  23. 請說明如何在 Webots 中設定機器人的初始位置和方向。
    A：選取 robot，修改 translation 與 rotation 欄位，或透過 Supervisor 程式設定。
  24. 在 Tutorial1 或 Tutorial2 中，如何讓機器人執行預設外的自訂動作？
    A：可修改控制器邏輯，加入自訂行為條件，例如不同感測器輸入對應不同運動策略。
  25. Webots 支援哪些主流程控制語言？各有何優缺點？
    A：支援 Python、C、C++、Java、MATLAB 等，其中 Python 易學易改，C/C++ 效能佳，Java 適合大型架構。
  26. 機器人控制器程式如何與其他程式（如資料記錄、遠端伺服器）進行通訊？
    A：可使用 TCP/IP socket、Webots ROS 介面，或將資料寫入檔案供外部程式讀取。
  27. Webots 的模擬世界中燈光和陰影設定如何影響感測器或相機的數據？
    A：光源會影響攝影機與光感測器的輸出，若光太暗或陰影多可能影響影像辨識準確性。
  28. 如何在 Webots 中調整機器人或感測器的物理參數（如質量、摩擦係數）？
    A：在 robot 或物件節點中修改 mass、friction、inertia 等欄位即可。
  29. 請說明如何使用 Webots 的 Console 與 Debug 工具協助程式錯誤排除。
    A：可在 Webots 底部 Console 查看 print 輸出或錯誤訊息，亦可用斷點與逐步執行進行除錯。
  30. Tutorial1、2 裡的機器人遇到物體時，碰撞偵測機制如何運作？
    A：機器人透過感測器偵測接觸或距離變化（如 bumper 或 IR sensor），觸發控制器邏輯反應。
  31. 若要將 Webots 模擬結果導出並進行數據分析，你會選擇哪些方法與工具？
    A：可將感測資料寫入 CSV 檔，使用 Python、MATLAB、Excel 等工具分析視覺、運動或控制成效。
